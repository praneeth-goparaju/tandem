# Alfred's avatar

The Slack app icon for Alfred.

**In use:** `alfred-avatar.png` (1024 by 1024), a black satin butterfly bow tie with a gold button on warm
cream; `alfred-avatar-512.png` is the same at 512. Chosen 2026-10-16. To set or change it: api.slack.com,
the app, Basic Information, Display Information, App icon (512 to 2000 pixels, square).

**Options** (`options/`, 1024 by 1024 PNGs, kept to switch later):

| File | Look |
|---|---|
| `bw1-classic-gold-cream` | Classic straight wings, gold button, cream (the first 3D bow tie) |
| `bw2-classic-gold-white` | The same on pure white |
| `bw3-butterfly-gold-cream` | Butterfly wings, gold button, cream (in use) |
| `bw4-butterfly-pearl-white` | Butterfly, glossy, pearl button, white |
| `bw5-batwing-silver-stone` | Slim batwing, matte, silver button, warm stone |
| `bw7-classic-onyx-white` | Classic, glossy, onyx button, white |
| `bw8-butterfly-none-stone` | Butterfly, matte, no button, stone |
| `bt1`–`bt8` | Bow tie in other colours: black on navy, burgundy, gold on charcoal, black on gold, navy polka dot, emerald, black on sage |
| `opt2-bowtie-3d`, `opt2-bowtie` | The first bow tie, 3D and flat |
| `opt3-face-3d`, `opt3-face` | Butler face (top hat, monocle, moustache), 3D and flat, on navy |
| `opt1-monogram` | Gold serif "A" in a ring, charcoal |
| `opt4-bubble` | Chat bubble wearing a top hat, teal |
| `opt5-cloche` | Silver serving cloche on a gold tray, green |
| `opt6-spark` | Flat top hat with sparkles, coral |
| `alfred-b`, `alfred-c` | Top hat on gold, top hat on midnight blue |

The `.svg` files are the sources of the flat designs and of the 3D foregrounds; the 3D PNGs add a lit
background and a soft shadow in Pillow.
