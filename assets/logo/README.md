# The tandem mark

One black stroke that loops twice, with a knot and a gold button at the
crossing: two riders on one path, and a bow tie for Alfred.

| File | Use |
|---|---|
| `tandem-mark.svg`, `tandem-mark-512.png`, `tandem-mark-1024.png` | The mark alone, transparent, for light backgrounds |
| `tandem-mark-light.svg`, `tandem-mark-light-512.png` | The mark in cream, for dark backgrounds |
| `tandem-tile.svg`, `tandem-tile-512.png`, `tandem-tile-1024.png` | The mark on a rounded cream tile: the README logo and the Slack app icon |

Colours: black `#1b1b1f`, gold `#e3c069` to `#a8822f`, cream `#f6efe2` to
`#efe6d6`. The SVGs are the sources; the PNGs are rendered from them with
cairosvg.

To set the Slack app icon: api.slack.com, the app, Basic Information, Display
Information, App icon. Use `tandem-tile-1024.png` (512 to 2000 pixels, square).
