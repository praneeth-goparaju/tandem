# Lessons

This folder records what went wrong in past agent runs and the rule that came out of it, so the same mistake does not happen twice.

- Read this folder before any run that changes the vault.
- One note per topic, for example `writes.md` or `reminders.md`. Each entry says what happened, the date, and the rule to follow now.
- Agents propose lessons; the owner adds them. Old lessons are never edited or removed.
- When a lesson matters to every run, the owner promotes it to a Hard Rule in `CLAUDE.md` and links back to the entry here.
